# Mac で使う（tl.dv なし・月額ゼロ・自分のPCで完結）

サーバーもクラウドも要りません。録音を放り込むと議事録になる、を **あなたの Mac の中だけ** で動かします。

## やることは3つだけ

### ① アプリを手元に置く
このリポジトリを ZIP でダウンロードして解凍（緑の「Code」→「Download ZIP」）。
解凍したフォルダの中の **`minutemate`** フォルダを開く。

### ② `start-mac.command` をダブルクリック
初回はガイドが出ます。順番に：

1. **Node.js が無ければ** → 自動で nodejs.org が開くので「LTS」を入れて、もう一度ダブルクリック。
2. **APIキーを2つ入れてね** と言われたら（どちらも無料・登録だけ）：
   - Gemini（議事録づくり）: https://aistudio.google.com/apikey
   - Groq（文字起こし）: https://console.groq.com/keys
   - 開いたテキストエディタの `GEMINI_API_KEY=` と `GROQ_API_KEY=` の後ろに貼って保存。
3. もう一度 `start-mac.command` をダブルクリック → 準備が走って、ブラウザで画面が開きます。

> ⚠️ 初回に「開発元を検証できません」と出たら、`start-mac.command` を **右クリック →
> 開く** を選ぶと実行できます（Mac の安全確認。1回だけ）。

### ③ 録音をドロップ
開いた画面（http://localhost:8788）の上の「🎙️ 録音をアップロード」に、
会議の録音ファイルをドラッグ＆ドロップ → タイトルと事業を選ぶ → **議事録が出ます**。

---

## 録音はどう用意する？（tl.dv の代わり）

- **Zoom**: 会議中の「レコーディング」ボタン → 「このコンピューターに記録」。終了後に音声ファイルができる。
- **Google Meet / その他**: Mac の画面収録（`Shift + Command + 5`）でも録れる。
- できたファイル（mp3 / m4a / mp4 / mov など）を ③ にドロップするだけ。

## 事業の分け方

`minutemate/businesses.yaml` を編集して、自分の事業を書いておくと、会議が自動でそこに振り分けられます。
（例：給付金 / ANTAI、ジュエリーダンジョン、など）

## よくある質問

- **月額かかる？** かかりません。Gemini も Groq も無料枠。録音も自分の Mac の中。
- **長い会議（1時間超）は？** `ffmpeg` があると自動で圧縮して処理します。無い場合は
  ターミナルで `brew install ffmpeg`（Homebrew）を入れると安心。短い録音はそのままでOK。
- **PCを閉じても動く？** この Mac ローカル版は「開いている間だけ」動きます。会議に自動入室
  させたい／閉じても動かしたい場合は、[DEPLOY.md](./DEPLOY.md) のサーバー運用へ。
- **データはどこ？** 全部 `minutemate/data/` の中（あなたの Mac）。外に出ません。
