# インスタ分析思考 2026（Web アプリ）

Instagram 運用の **KPI ツリー分析フレームワーク** を Web アプリ化したものです。
週次・投稿別の数値を入力するだけで各種レートが自動計算され、目安値との比較で
詰まり箇所が可視化され、該当する診断フロー（チェックポイント＋具体アクション）へ
直接飛べます。

> **数字を入れる → どこが悪いか分かる → 何をすべきか分かる** までを1つのアプリで完結。

- データは **localStorage のみ**（v1 は認証・DB・API なし／1ユーザー前提）
- コンテンツ（KPI 定義・診断フロー・2026 年の変更点）は `insta_data.json` を読み込み
- 日本語 UI・モバイルファースト・ライト/ダーク対応

## いちばん簡単な使い方（インストール不要）

**このリポジトリの [`インスタ分析思考2026.html`](./インスタ分析思考2026.html) を1ファイルだけダウンロードして、ダブルクリックで開く** だけで動きます。
Next.js 版と機能は同じ（全6画面・自動計算・診断フロー・サンプル投入・JSON/CSV 入出力）で、
外部通信ゼロ・データは開いた端末の中だけに保存されます。スマホでもそのまま使えます。

> このHTMLは `src/` のアプリと同じロジックを1枚に収めた単一ファイル版です。
> 元データを差し替えたい場合は `insta_data.json` を編集してから再ビルドしてください。

以下は、開発してカスタマイズしたい場合の Next.js 版の手順です。

## 動作確認手順

```bash
npm run build   # 本番ビルド（TypeScript 型チェック込み）。警告なしで通ることを確認
npm run lint    # ESLint（0 problems）
npm run start   # ビルド済みアプリを起動して手動確認
```

手動での確認ポイント：

1. **ダッシュボード（空状態）** の「サンプルデータを投入（開発用）」を押すと、
   週次3週分＋投稿5件が入り、KPI カード・スパークライン・アラートが表示される。
   （サンプルはシェア率が3週連続で低下するよう作ってあり、2週連続低下アラートが出ます）
2. アラートの「診断フローを見る →」で `/diagnosis?kpi=…&state=減った` に飛ぶ。
3. **週次分析**：14項目を入力 → 10種レートが自動計算（分母ゼロ・未入力は「—」）。
   一覧の編集・削除、レート選択で折れ線グラフ（目安値を点線表示）。
4. **投稿別分析**：形式・判定でフィルタ、各レートでソート、勝ち/負けサジェスト。
   「勝ちパターン」タブに勝ち投稿がネタ帳として並ぶ。
5. **設定**：目安値・判定しきい値の編集、JSON エクスポート/インポート、
   週次・投稿別の CSV エクスポート、全データ削除（確認ダイアログ）。

## 画面構成

| パス | 画面 | 概要 |
|---|---|---|
| `/` | ダッシュボード | 最新週の KPI カード（前週比・3色ステータス）／主要4レートのスパークライン／2週連続低下アラート |
| `/weekly` | 週次分析 | 14項目入力→10レート自動計算／一覧（編集・削除）／レート別折れ線グラフ |
| `/posts` | 投稿別分析 | 投稿ごとの入力→5レート自動計算／フィルタ・ソート／勝ち負けサジェスト／勝ちパターン一覧 |
| `/diagnosis` | 診断フロー | ① KPI → ② 状態 → ③ 打ち手カード（「試した」チェック＝日付付きで記録） |
| `/kpis` | KPI 辞典 | KPI 14件の定義・目安／「2026年に変わったこと」14件 |
| `/settings` | 設定 | ベンチマーク・判定しきい値の編集／データ管理（JSON/CSV/全削除） |

## 計算ロジック（`src/lib/calc.ts`）

すべて純関数。ゼロ除算・未入力（`null`）は `null`（画面上は「—」）を返します。

**週次レート**

- フォロワー増加率 = 新規フォロワー ÷ 週初フォロワー数
- ホーム率 = フォロワーリーチ ÷ 週初フォロワー数
- フォロワー外リーチ率 =（リーチ − フォロワーリーチ）÷ リーチ
- プロフアクセス率 = プロフィールアクセス ÷ リーチ
- フォロワー転換率 = 新規フォロワー ÷ プロフィールアクセス
- 保存率 = 保存 ÷ リーチ
- シェア率 = シェア ÷ リーチ
- リンク CTR = 外部リンククリック ÷ プロフィールアクセス
- ストーリーズ閲覧率 = ストーリーズ閲覧 ÷ 週初フォロワー数
- 成約率 = CV数 ÷ 外部リンククリック

**投稿レート**（分母はビュー数。維持率のみ 平均視聴時間 ÷ 動画尺）

- 維持率／いいね率／保存率／シェア率／プロフアクセス率

## データの持ち方 / 将来の拡張

永続化は `src/lib/store.ts` の **データアクセス層** に閉じ込めてあります
（`useWeekly` / `usePosts` / `useSettings` / `useChecks` と各 `*Repo`）。
`useSyncExternalStore` ベースで SSR セーフ。localStorage キーは名前空間
`insta-analytics-2026:*` に統一しています。

将来 Supabase 等でマルチユーザー化する場合は、この `store.ts` の実装（`createStore`
と各 `*Repo`）を差し替えるだけで、画面側のコードはほぼそのまま流用できます。

**v1 の非スコープ**：認証・マルチユーザー・Instagram API 連携・サーバーサイド処理。
