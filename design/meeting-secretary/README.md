# ミーティング秘書アプリ（仮称: MinuteMate）設計書

tl.dv のような「会議の全自動秘書」アプリの設計ドキュメント一式。

## コンセプト

> Zoom / Google Meet の開始を自動検知して全ミーティングに入室し、
> 録画・文字起こし・議事録・タスク抽出・共有リンク発行までを全自動で行う。
> さらに「事業」を登録しておくと、会議を事業ごとのフォルダに自動振り分けし、
> 事業単位の進捗レポートと次回アジェンダ（NA: Next Action）まで生成する
> —— つまり「打ち合わせの秘書」。

## 3行サマリ

1. **入口**: Google カレンダー同期 + Zoom Webhook で会議を検知し、会議ボット（コンテナ）が自動入室して録画。
2. **処理**: 録画 → 文字起こし（話者分離付き）→ Claude による議事録 / タスク / NA / 事業分類の生成。
3. **出口**: 事業ごとのフォルダに自動整理、共有リンク発行、Slack / メール通知、事業進捗ダッシュボードと週次進捗レポート。

## 最重要の設計判断（先に結論）

| 論点 | 結論 | 理由 |
|---|---|---|
| ボット入室の実装 | **MVP は Recall.ai 等のボット API を採用し、将来内製化** | 内製ボット（headless Chromium + 仮想オーディオ）は運用が重い。まず価値検証を優先 |
| 文字起こし | Deepgram（日本語対応・話者分離込み）を第一候補、Whisper をフォールバック | 精度・速度・診断のしやすさ |
| LLM | Claude API（議事録/タスク/進捗: Sonnet、分類/軽処理: Haiku） | 長文コンテキストと構造化出力の安定性 |
| 長時間ワークフロー管理 | Temporal | 「入室待ち→録画→後処理→配信」の多段・長時間・失敗リトライを堅牢に |
| ストレージ / 共有リンク | S3 + CloudFront 署名付き URL + 共有ページ | 有効期限・パスワード・権限制御を自前で持てる |
