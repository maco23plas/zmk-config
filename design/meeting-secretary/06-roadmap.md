# 06. ロードマップ・MVP・リスク

## 1. フェーズ計画

### Phase 0 — 検証 MVP（2–3 週間）

**ゴール: 「URL を渡すと録画+議事録+タスク+共有リンクが返ってくる」を自分の実会議で毎日使える状態にする。**

- 会議 URL 手動登録 → Recall.ai でボット入室・録画
- Deepgram 文字起こし（話者分離）→ Claude 議事録 + タスク抽出
- 共有リンク（署名付き URL の簡易共有ページ）
- 事業は**手動タグ付け**のみ（分類 AI はまだ）・シンプルな一覧 UI
- 通知はメールのみ
- インフラ最小構成: Next.js + API + Postgres + S3。Temporal はこの時点から導入（後から入れる方が高くつく）

**Phase 0 で検証すること**: 議事録品質が「秘書代わり」に足るか / 入室成功率 / 1会議あたりコスト実測

### Phase 1 — 全自動化（+4–6 週間）

- Google カレンダー連携: 予定からの自動検知・自動入室（watch + 増分同期）
- Zoom OAuth + Webhook（突発会議対応）
- 入室ポリシー（全参加/主催のみ/除外リスト）
- Slack 通知、待機室タイムアウト等の運用系
- 議事録編集 UI、録画プレイヤー + トランスクリプト同期ジャンプ

### Phase 2 — 「事業秘書」化（+6–8 週間）＝差別化の本丸

- 事業エンティティ + AI 自動分類 + 未分類インボックス + 修正学習ループ
- 事業フォルダビュー / 事業ダッシュボード（タスク・決定事項タイムライン）
- 週次進捗レポート自動生成・配信
- NA 生成 + 次回会議の事前ブリーフ配信
- Google Drive 自動エクスポート（事業フォルダ）、タスクの持ち越し追跡

### Phase 3 — スケールと堀（以降）

- 内製ボット Fleet（変動費 1/10 化、データ経路の完全内製化）
- 横断セマンティック検索・RAG 質問応答（「あの話どこでしたっけ？」）
- Notion / Asana / Linear タスク同期、Teams 対応
- チーム向け権限の細分化、SSO、監査ログのエクスポート

## 2. MVP チーム・体制の目安

| 役割 | Phase 0–1 |
|---|---|
| フルスタック 1–2 名 | Web/API/パイプライン（TypeScript で統一しているため兼務可能） |
| AI エンジニア（兼務可） | プロンプト設計・Eval・話者マッピング |
| デザイン | UI キットベースで最小限（shadcn/ui） |

## 3. 主要リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| **プラットフォーム規約** — Zoom/Google のボット・録画ポリシー変更 | 致命的 | ボット API ベンダー（Recall）の規約追従に相乗り。Zoom は公式 OAuth アプリ審査を早期に通す。録画告知を必ず行い「隠し録音」ポジションを取らない |
| Google Meet の突発会議が検知できない | 機能制約 | 仕様として明示し、ボット招待メール/URL貼付の UX を磨く。カレンダー起点の会議が大半という前提を Phase 0 で実測 |
| 待機室で入れない・蹴られる | 信頼低下 | 入室成功率を KPI 化（98%）。失敗の即時通知と「録画なしでも議事録なし理由が残る」誠実な UI |
| 議事録品質が期待に届かない | 解約 | 根拠リンク必須設計（05）+ ゴールデンセット回帰評価 + 編集 UI で「直せる」逃げ道 |
| 録画データの扱いへの不安（営業先など） | 導入障壁 | 保持期間設定・ワンクリック削除・共有範囲の既定を狭く。SOC2 は Phase 3 で検討 |
| 変動費が価格を圧迫 | 利益率 | 実測 $1.2–1.8/時間（05）→ 席課金 + 録画時間上限のハイブリッド価格。Phase 3 の内製ボットで原価 1/3 以下へ |
| tl.dv 等の競合が「事業軸」を実装してくる | 差別化喪失 | 分類修正データと事業ナレッジ（会議履歴の構造化蓄積）がスイッチングコストになる。速く Phase 2 に到達する |

## 4. 価格設計の初期仮説（参考）

| プラン | 想定 | 月額の目安 |
|---|---|---|
| Free | 月 5 会議・保持 14 日・共有リンクのみ | ¥0（獲得用） |
| Pro | 無制限録画（フェアユース）・事業 3 つ・進捗レポート | ¥3,000–5,000/席 |
| Business | 事業無制限・Drive/Notion 連携・権限管理・保持無制限 | ¥8,000–12,000/席 |

原価 ~¥200–280/会議時間（Phase 0–2）を踏まえ、Pro の損益分岐は月 ~15–20 時間録画/席。ヘビーユーザー向けに録画時間の従量アドオンを用意。

## 5. 最初の一歩（次のアクション）

1. Recall.ai のサンドボックスで「Meet に入室 → 録画取得」の技術検証（1 日）
2. Deepgram で日本語会議 3 本の文字起こし品質確認（話者分離含む）（1 日）
3. 議事録プロンプトのプロトタイプ: 手元の会議録音 → Claude → 構造化議事録の品質を関係者レビュー（2–3 日）
4. 上記が OK なら Phase 0 の実装着手（リポジトリ雛形: Turborepo + Next.js + NestJS + Prisma + Temporal）
