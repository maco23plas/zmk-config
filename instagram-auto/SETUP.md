# インスタ分析 自動取得セットアップ（運用代行向け）

あなたの分析シート（Googleスプレッドシート）に、権限を持っている**全クライアントのIGインサイト**を自動で貯める仕組みです。
サーバー不要・無料。`Code.gs` をシートに貼るだけで動きます。

```
毎日21時   → 公開中ストーリーズを記録（24時間で消えるので毎日）
毎週月曜7時 → 前週(月〜日)のアカウント週次＋投稿別を記録
毎週水曜   → アクセストークンを自動延長
```

書き込み先は新規タブ4枚だけ（既存のシートには一切触りません）:
`RAW_アカウント週次` / `RAW_投稿` / `RAW_ストーリーズ` / `RAW_ログ`

---

## 準備0：前提の確認（5分）

- クライアントのIGが**プロアカウント**（ビジネス/クリエイター）で、**Facebookページと連携済み**
- そのページに、**あなたのFacebookアカウントが管理者/編集者権限**を持っている
  （Meta Business Manager でパートナー共有されていればOK）

## 準備1：Metaアプリを作る（10分・審査不要）

1. https://developers.facebook.com/ → 「マイアプリ」→「アプリを作成」
2. ユースケースは「その他」→ 種類「ビジネス」でOK。名前は自由（例: insta-bunseki）
3. 作成後、**アプリID** と **app secret**（設定 > ベーシック）を控える
4. アプリは**開発モードのまま**でOK。自分しか使わないので審査・公開は不要です

## 準備2：トークンを1回発行する（5分）

1. https://developers.facebook.com/tools/explorer/ （Graph APIエクスプローラ）を開く
2. 右上で自分のアプリを選択
3. 「ユーザートークンを生成」で、次の権限（アクセス許可）を追加して「Generate Access Token」:
   - `instagram_basic`
   - `instagram_manage_insights`
   - `pages_show_list`
   - `pages_read_engagement`
   - `business_management`
4. 表示されたトークンをコピー（短期でOK。スクリプトが約60日の長期トークンに交換し、以後は毎週自動延長します）

## 準備3：スクリプトを貼る（5分）

1. 分析シートを開く →「拡張機能」→「Apps Script」
2. エディタに `Code.gs` の中身を全部貼り付けて保存
3. シートに戻ってリロード → メニューに「📊 インスタ自動取得」が出る
4. 「① 初期設定（トークン登録）」→ アプリID / app secret / トークン を貼る
5. 「接続テスト」→ 取得できるクライアントのアカウント一覧が出れば成功
6. 「② 今すぐ取得（前週分）」で動作確認 → RAW_タブにデータが入る
7. 「③ トリガー設置」で自動化ON（初回は権限承認ダイアログが出ます）

## 取れるもの／取れないもの（正直な対応表）

あなたのシートの列との対応：

| シートの列 | API | 備考 |
|---|---|---|
| 閲覧数 | ✅ `views` | 投稿別・アカウント週次とも |
| リーチ数 | ✅ `reach` | 同上 |
| インタラクション数 | ✅ `total_interactions` | いいね・コメント・保存・シェア等の合計 |
| 投稿からのフォロー数 | ✅ `follows` | 投稿単位 |
| プロフアクセス数（投稿） | ✅ `profile_visits` | 投稿単位 |
| プロフのリンクタップ（週次） | ✅ `profile_links_taps` | 旧 website_clicks の代替 |
| フォロワー増加数（純増） | ✅ `follower_count` 日次合計 | フォロワー100人未満は返らないことあり |
| リール平均視聴時間 | ✅ `ig_reels_avg_watch_time` | 秒に換算して記録 |
| ストーリーズ閲覧数・DM(返信) | ✅ 毎日自動記録 | 24時間で消えるため日次取得 |
| ストーリーズのリンクタップ数 | ⚠️ | リンクスタンプ単体の数はAPI非対応。`navigation` を参考値として記録 |
| 外部リンククリック数（投稿） | ❌ 手入力継続 | v21で `website_clicks` 等が廃止 |
| リール動画の長さ／視聴完了率 | ❌ 手入力継続 | 動画長はAPIで取れないため、完了率は「平均視聴÷長さ」を手計算 |
| フォロワー外閲覧率 | ❌ 手入力継続 | フォロワー内/外の内訳はダッシュボードのみ |
| アクション数（ｱﾝｹｰﾄ等） | ❌ 手入力継続 | スタンプ反応はAPI非対応 |

**まとめ：転記作業の7〜8割が自動化**され、残り（外部リンク・完了率・フォロワー外率・スタンプ反応）だけ手入力です。

## 運用上の注意

- **90日制限**：APIは過去90日程度しか遡れません。この仕組みは「毎週貯める」前提です（貯めた分はシートに永久に残る）
- **トークン失効**：万一切れたら（RAW_ログにエラーが出ます）、準備2→①初期設定をやり直せば復旧
- **新しいクライアント**：ページ権限をもらえば**次回実行から自動で対象に追加**されます（設定変更不要）
- **指標の改廃**：Metaは指標をたまに廃止します。廃止された指標は空欄でスキップされ、他は動き続けます（RAW_ログに「指標スキップ」と記録）

## Webアプリ（インスタ分析思考 2026）との連携

`RAW_アカウント週次` の列は、Webアプリの週次入力（リーチ／保存／シェア等）の元データになります。
必要なら「RAW_タブ → アプリのJSONインポート形式」の変換もこちらで作れます。
