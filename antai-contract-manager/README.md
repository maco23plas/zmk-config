# アンタイ 契約・入金管理ツール

アフィリエイターと共有している流入シートとは**別ファイル**で運用する、社内専用の契約・入金管理。
Webアプリではないので**デプロイ作業は不要**（貼り付けて①を押すだけ）。

## なぜ別ファイルなのか
流入シート（エルメ_ログ同期）はアフィリエイターに共有されているため、
契約金額・入金状況・顧客の個人情報を置けない。読み取り専用で参照するだけにして、
機微な情報はこちら側に閉じる。

## 決定事項（2026-09-11）
- **成約の定義＝契約締結**（面談直後の時点）
- **代理店・アフィリエイターへの支払い＝入金ベース**（着手金の入金確認後に起票）
- 決済は **Stripeを外部に置く**。面談中に即決できる人はその場で決済、できない人はLINEで案内
- 電子契約は **クラウドサイン導入済み**
- 現在の課題：**その場で契約書にサインしてもらえない／当日決済に至らない**

## シート構成
| シート | 役割 |
|---|---|
| ダッシュボード | 今月の契約・入金・未回収、**即決率**、要対応リスト、流入元別 |
| 契約管理 | 1契約1行。入力するのは白いセルのみ、グレーの4列は自動計算、右端の緑が「操作」 |
| 代理店報酬 | 入金確認済みの案件から自動起票。承認と支払だけ人が押す |
| マスタ | プラン標準金額・代理店ごとの報酬単価 |
| 設定 | 流入シートURL・通知先・期限の既定値 |

## ふだんの使い方（操作は3つだけ）
1. 契約が決まったら、契約管理の行に **氏名・メールアドレス・契約日・プラン** を入れる
   → 契約金額・着手金の期限が自動で入り、決済リンクも自動で発行される
2. 右端の **「操作」列** で `案内を送る（契約書＋決済リンク）` を選ぶ
   → クラウドサインで契約書を送付し、決済リンクを載せた案内メールを本人へ送信
3. あとは待つだけ。入金は毎朝自動で取り込まれ、進行状況とダッシュボードが更新される

**「操作」列でできること**（選ぶと即実行され、選択はすぐ空に戻る）

| 選択肢 | 何が起きるか |
|---|---|
| 案内を送る（契約書＋決済リンク） | 契約書送付・決済リンク発行・案内メール送信をまとめて実行。済んでいる分は飛ばすので二重送信にならない |
| 入金を確認する | その行だけStripeに問い合わせ。入金があれば入金日を埋めて紹介報酬も起票 |
| キャンセルにする | キャンセル日を入れる。入金済みなら要対応に返金対応が出る |
| 返金する | 確認ダイアログのうえでStripe返金を実行し、返金額・返金日を記録 |
| CS（公式LINE）へ引き継ぐ | CS移行日を入れる |

案内メールの件名・本文は設定シートの `MAIL_SUBJECT` / `MAIL_BODY` で差し替えられる
（`{氏名}` `{プラン}` `{金額}` `{契約書URL}` `{決済リンク}` `{期限}` が使える）。

## 動作チェック
メニューの **🔍 動作チェック** は何も書き換えずに読むだけで、流入シート・列と数式・
マスタ・トリガー・通知先・メール送信枠・Stripe・クラウドサインをまとめて点検する。
キーとモードの食い違い（本番モードにテスト用キーが入っている等）もここで分かる。

## 本番の決済を作らずに試す
設定シートの `STRIPE_MODE` を `テスト` にし、`STRIPE_SECRET_KEY_TEST` に `sk_test_…` を入れる。
本番キーはそのまま残るので、確認後は `STRIPE_MODE` を `本番` に戻すだけでよい。
テスト中は商品名に【テスト】が付き、ダッシュボード最上段に赤い警告が出る。

## 自動でやること
- **進行状況**（未契約／着手金待ち／残金待ち／完了）を自動判定
- **要対応**を自動検出
  - 契約日があるのにクラウドサインが締結済でない → 「契約書 未締結」
  - 入金期限を過ぎている → 「着手金 遅延◯日」「残金 遅延◯日」
  - 面談から既定日数が経っても契約がない → 「面談後◯日 未契約」
- 契約日を入れると**着手金の期限を自動で埋める**（既定7日後）
- プランを選ぶと**契約金額を自動で埋める**
- 毎朝、**入金・返金・締結状況の取り込み → 紹介報酬の起票 → ダッシュボード更新 → 要対応の通知**
  （手動で回したいときはメニューの「🔄 いま最新にする」）

## 即決率について
「面談中に締結できた割合」「面談中に決済できた割合」をダッシュボード最上段で計測する。
いまの課題を数値で追えるようにするため、契約方法・決済方法は
「面談中に締結／後日締結／未締結」「面談中に決済／LINE案内／銀行振込」から選ぶ形にしている。

## データ元（どこから計算しているか）
| # | データ元 | 取ってくるもの | 取得方法 |
|---|---|---|---|
| 1 | 流入シート「顧客」タブ | LINE ID・氏名・QR名・面談予約日時 | メニュー②（読むだけ、書き換えない） |
| 2 | 契約管理シートの入力 | 契約日・プラン・金額・担当など | 人が入力 |
| 3 | マスタ | プラン金額・報酬単価・チャネル一覧 | 人が設定 |
| 4 | **Stripe API** | 決済リンク・入金・返金 | 編集時の自動発行／「操作」列／毎朝の自動実行 |
| 5 | **クラウドサインAPI** | 契約書の送付・締結状況 | 「操作」列／毎朝の自動実行 |

## Stripe連携でできること
- **決済リンクの自動発行**：契約日とプラン（金額）が入ると、その行の決済リンクが自動で作られる。
  手動で作りたい場合はメニュー⑥。着手金額があればその額、無ければ契約金額でリンクを作る
- **入金の自動反映**：Stripe側で支払われると、決済ステータスが「支払済」になり、
  着手金の入金日が自動で埋まる（メニュー⑦／毎朝の自動実行）
- **返金の検知**：Stripeで返金が行われていれば、返金額と返金日を自動で取り込む
- **返金の実行**：「操作」列の `返金する`。お金が動くので確認ダイアログを必ず挟む

## キャンセルになったとき
「キャンセル日」を入れると、進行状況が `キャンセル(返金未)` に変わり、
要対応に **返金対応 ¥◯◯◯** と返すべき金額が出る。返金すると `キャンセル(返金済)` になる。

## 紹介報酬の支払予定
入金を確認できた案件だけが自動で起票される。支払期日は設定の
`REWARD_PAY_RULE`（当月末／翌月末／翌々月末）から自動計算。
ダッシュボードに **期限切れ／今月／来月／それ以降／未承認** の金額と紹介者の内訳が出る。

## セットアップ
1. 新しいスプレッドシートを作る（**誰とも共有しない**）
2. 拡張機能 → Apps Script → `gas/契約管理.gs` を貼り付けて保存
3. スプレッドシートを再読み込み → メニュー「📗 契約管理」→「⚙ はじめの設定」
4. 「設定」シートに流入シートのURL・Stripeキー・通知先を入力
5. メニュー「📥 流入シートから取り込む」
6. メニュー「🔍 動作チェック」で赤が出ないことを確認

メールを送る権限が増えているため、貼り替えたあと最初の実行で
Googleの認証画面がもう一度出る。許可すれば以降は出ない。
